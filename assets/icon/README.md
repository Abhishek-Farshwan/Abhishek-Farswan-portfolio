# Game Icon Pack

The icons in this folder come from [Game Icon Pack by Nieobie](https://nieobie.itch.io/free-icons).

The creator releases the pack under the [CC0 1.0 Universal license](https://creativecommons.org/publicdomain/zero/1.0/), allowing the icons to be used, modified, shared, and redistributed. Credit is optional, but appreciated. Check the source page for updates to the pack or license details.

## Folder Layout

- The numbered category folders contain the downloaded icon library.
- `selected/` contains the small shortlist identified for possible use in this portfolio.
- Keep the original category folders intact when updating `selected/`, so unused icons remain available for future reference.

Icons are not loaded by the website just because they are stored here. They are downloaded by visitors only when referenced by the page's HTML, CSS, or JavaScript.
